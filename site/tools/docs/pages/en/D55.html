Kilnframe Desktop is made for Macs with Apple silicon (M1 and later).

Install

Download it, open the file and drag Kilnframe Desktop into Applications (Install). Keep it there: the settings copied for ChatGPT, Claude Desktop and Codex point at the app where it is (Connect AI assistants).

Permissions

macOS asks the first time a feature needs one. You can also give them in System Settings › Privacy & Security:

  • Screen & System Audio Recording, to record the screen. macOS asks to reopen Kilnframe afterwards.
  • Camera and Microphone, for the recorder and voice-over.
  • Input Monitoring, to record clicks for the mouse highlight.

Recording the computer's own sound needs macOS 14.2 or later.

Updates and keys

The app asks before it downloads and installs a new version (Updates). Your API keys and licence are kept in the macOS Keychain. Exports use the Mac's own video encoder.
