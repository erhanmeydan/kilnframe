On Windows, Kilnframe Desktop comes from the Microsoft Store, for x64 and Arm64 computers, as a Beta.

What Beta means

Every feature is there. Beta says that the Windows version is newer and gets fixed quickly from what users report: if something goes wrong, use Report a problem (Report a problem).

Install and updates

Install it from the Microsoft Store (Install). The Store keeps it up to date; there is nothing else to download.

Export

With Hardware acceleration, exports use your NVIDIA, AMD or Intel graphics and run several times faster.

AI and connections

  • Claude Code and Codex open their sign-in in a Command Prompt window (Claude or ChatGPT plan).
  • Claude Desktop, ChatGPT and Codex connect over MCP the same way as on a Mac: press the client's button in Settings › Connections and paste what it copies. The copied command starts kilnframe-mcp.exe, a command the Store package adds to Windows and keeps up to date with the app (Connect AI assistants).
  • Your API keys and licence are kept in Windows Credential Manager.

Camera and microphone

For the recorder and voice-over, Settings › Privacy & security › Camera and Microphone must let desktop apps use them.
