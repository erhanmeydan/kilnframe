On Linux, Kilnframe Desktop is one AppImage file, for x64 and Arm64 computers, as a Beta.

Install and run

Download the AppImage, allow it to run as a program, and double-click it (Install).

Updates

When a new version is out, the app says so and offers Open Download Page. Download the new AppImage and use it in place of the old one; the app does not install updates by itself on Linux (Updates).

Keyring

Your API keys and licence are kept by the system's secret service. A keyring such as GNOME Keyring or KWallet must be running; without one, a licence is kept only until you quit, and the Licence window says so.

Recording

Clicks cannot be recorded on a Wayland desktop; on X11 they need xinput. Where the pointer is is recorded either way (Record screen and camera).

Export

With Hardware acceleration, exports use an NVIDIA graphics card when there is one.

Beta

Every feature is there; if something goes wrong, use Report a problem (Report a problem).
