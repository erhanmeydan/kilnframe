Troubleshooting

The messages you may meet, what they mean, and what to do.

The AI model does not connect

  • not installed next to Claude Plan or ChatGPT Plan: Claude Code or Codex is missing. Copy the Install command, run it, and press Look Again (Claude or ChatGPT plan).
  • signed out: press Sign In and confirm in the browser.
  • update: an old version can stop working; press Update.
  • Could not connect. after Test Connection: check the key, the address of a custom endpoint, or that LM Studio or Ollama is running (API keys, Local models).
  • Connected, but the model did not read the picture.: choose a model that reads images.

A recording does not start

The recorder says which permission is missing and offers Open Settings. On a Mac allow Screen & System Audio Recording, Camera and Microphone, then reopen Kilnframe; on Windows let desktop apps use the camera and microphone. On a Linux Wayland desktop clicks are not recorded (Record screen and camera). If the camera is in use by another app, close it or choose None.

A file is missing

A clip says Missing. Find it: the file is not where the project left it. Open File › Find Media… and find it; the others in the same folder come with it (Projects and files).

Playback is slow

  • Set Playback quality to Smooth: a phone's 4K or HEVC video then plays from a light copy (Program).
  • Heavy work slows the app while it runs; Running work under the viewer shows it and can stop it.
  • If the caches filled the disk, Settings › Storage › Empty Caches Now.

Export is slow

Tick Hardware acceleration in the Export window. Smooth slow motion (Make new frames) makes the export take longer, and the window says so.

Licence messages

  • This key is in use on 2 computers. Remove one of them first.: free one with Remove This Computer there.
  • The licence could not be checked for 3 weeks. Connect to the internet once.
  • On Linux, a key kept only until you quit: start a keyring service such as GNOME Keyring or KWallet (Licence and trial).

MCP: the port is in use

Another program took the port, so the server listens on another for now and says so. Copy the command for Claude Code, Cursor and other clients again (Connect AI assistants).
