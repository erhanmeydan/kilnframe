ACCOUNT AND PRIVACY

Updates

New versions arrive by themselves; how they are installed depends on the system.

Mac

The app looks for a new version when it starts and every few hours. When there is one, it asks: Kilnframe Desktop … is out. You have …, with Update now or Later. It downloads only when you agree. Then Restart and install, or Install on quit to do it the next time you quit. After Later, the top bar keeps an Update available button.

Windows

The Microsoft Store keeps the app up to date, as it does every Store app. To check by hand, open the Store's Downloads and updates page; the app's own Check for updates opens it for you.

Linux

The app tells you when a new version is out and offers Open Download Page. Download the new AppImage and use it in place of the old one (Install); the app does not install updates by itself on Linux.

Check by hand

Settings › General › Updates shows Your version and Check for updates. If the check fails, check your internet connection and try again.

Your projects are not changed by an update.
